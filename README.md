# Abdallah Ewies: data analysis demo portfolio

Three original demo projects in SQL, Excel and Python, with interactive dashboards.

Live site: https://abdallah-ewies.github.io

All three are demos. None is client work. Power BI and Tableau are listed as self-reported tools; these demos are not built in them.

Data sources: World Bank, World Development Indicators (CC BY 4.0 as listed in the World Bank indicator metadata, https://datacatalog.worldbank.org/public-licenses), recalculated by the author and not endorsed by the World Bank. The churn project uses synthetic data and the budget model uses invented numbers.
